## Почему SquidyGit?

Я не нашёл под Linux Git-клиент, который был бы удобен для моей повседневной работы.
Одни приложения оказались слишком ограниченными, другие — перегруженными, а многим не
хватало удобного сочетания истории репозитория, индексации изменений и управления ветками
в одном нативном интерфейсе. Поэтому я решил написать собственное приложение.

SquidyGit оставляет основные операции Git на виду и не скрывает используемые инструменты.
Приложение работает через системный `git`, а все выполняемые команды доступны во встроенном
журнале.

## Возможности

- Вкладки репозиториев, закладки и восстановление предыдущей сессии
- Раздельные списки проиндексированных и непроиндексированных файлов
- Плоское представление и дерево каталогов, фильтр и цветные статусы
- Просмотр unified diff с номерами старых и новых строк и подсветкой изменений
- Индексация и откат по отдельным ханкам или строкам
- Коммит, исправление предыдущего коммита и автоматический push после коммита
- Визуальный граф истории с ветками, тегами и merge-коммитами
- Создание, переключение, переименование и удаление веток, merge и rebase
- Fetch, pull и push с настройкой upstream, отправкой тегов и `--force-with-lease`
- Управление stash, тегами, удалёнными репозиториями и подмодулями
- Поиск коммитов по описанию, автору, содержимому, пути или SHA
- Светлая и тёмная темы
- Встроенный журнал всех выполненных команд Git

## Технологии

SquidyGit — нативное приложение на C++20, использующее:

- Qt 6: Core, Gui, Widgets и Concurrent
- CMake 3.16 или новее
- Системный клиент Git

Дополнительная runtime-библиотека или встроенная реализация Git не требуется.

## Сборка

### Linux

Установите компилятор с поддержкой C++20, CMake, Git и пакеты разработки Qt 6:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
./build/SquidyGit
```

Установка приложения, desktop-файла и иконок для текущего пользователя:

```bash
cmake --install build --prefix ~/.local
```

Сборка DEB-пакета для Debian/Ubuntu:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target deb_package
```

Цель `deb_package` всегда использует отдельную Release-сборку, даже если
текущий профиль CLion настроен на Debug. В CLion обновите CMake, выберите
`deb_package` в окне CMake и запустите сборку цели. Готовый пакет будет создан в
`build/dist`.

### Windows

Установите Qt 6 с MinGW и передайте CMake путь к Qt:

```powershell
cmake -S . -B build -DCMAKE_PREFIX_PATH=C:/Qt/6.x.x/mingw_64
cmake --build build --parallel
.\build\SquidyGit.exe
```

При сборке на Windows автоматически запускается `windeployqt`, который копирует необходимые
компоненты Qt рядом с исполняемым файлом.

Для сборки автономного Windows-установщика установите Qt Installer Framework и выполните:

```powershell
cmake --build build --target windows_installer
```

Готовый файл появится по пути `build/dist/SquidyGit-0.0.1-windows-x64.exe`. Установщик
устанавливает SquidyGit в `Program Files`, создаёт ярлыки на рабочем столе и в меню «Пуск»,
а также добавляет программу удаления. Во время установки Windows запросит права администратора.

## Безопасность

Потенциально опасные действия — откат изменений, hard reset и удаление веток — требуют
подтверждения. Интерактивный запрос учётных данных отключён, поэтому для приватных
репозиториев необходим SSH-ключ или настроенный Git credential helper.
